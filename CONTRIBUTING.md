# Contributing

Tutte le contribuzioni, segnalazioni di bug, correzioni di bug, miglioramenti della documentazione, potenziamenti e idee sono benvenuti.

## Come contribuire

1. Fai un fork del repository
2. Crea un nuovo branch (git checkout -b feature-branch)
3. Fai commit delle modifiche
4. Fai push sul branch
5. Apri una Pull Request

Grazie per contribuire!
